## 0. 用語（このページで使う言葉）

| 言葉 | 意味 |
|---|---|
| **バックテスト** | 過去のデータで「もしこの戦略で売買していたら」を試すこと |
| **前進検証**（walk-forward） | 過去3年で売買ルールを決めて、次の1年で試す。窓をずらして16回繰り返す。**未来を見ない** |
| **in-sample** | 全期間を見た後で、その期間に当てはめること。**答えを見てから採点するようなもの** |
| **OOS**（out-of-sample） | 学習に使っていない期間で試すこと。前進検証はこれ |
| **イベントスタディ** | 「米中関税発表」のような**事件の前後**で指標が動いたかを調べる分析。バックテストとは別物 |
| **pre上昇** | 事件が**起きる前**に指標が上がっていたか。上がっていれば「予兆を捉えた」と言える |
| **イベントの客観的定義** | どの日を「事件」と呼ぶかを機械的なルール（例: VIXが○○超え）で決めること。**人間が選ぶと恣意的**になる |
| **ホールドアウト** | データの一部を**最初から隠しておいて**、手法が完成してから初めて試すこと |
| **窓依存** | 何日分のデータで計算するかで結果が変わってしまうこと |
| **p値** | 「偶然でもこれくらい起きる確率」。小さいほど偶然ではない。0.05未満が慣習的な基準 |
| **Δσ**（デルタシグマ） | 事件前後で指標が標準偏差の何個分動いたか。大きいほど強く反応 |
| **Sharpe（シャープ比）** | リスク1単位あたりのリターン。高いほど効率的 |
| **MaxDD（最大下落）** | 一番高かった時点から、どれだけ落ちたか |

## 2. やったけど載せなかった ＝「検証したが脆かったので載せていない」で答える

**載せなかったのは悪いことではなく、選別した証拠。** ただし何を選別したかは把握しておく必要がある。

### 2-1. イベントスタディ系（事件前後の分析）→ 核から外した

| 何を | 結果 | なぜ載せないか |
|---|---|---|
| **事件前の指標上昇（pre上昇）** | 手動28件で p=0.0018 だが、**窓を40日にすると消える**（p=0.787） | **窓の取り方で結論が変わる**＝脆い |
| **VIX→L¹ の先行性（lead-lag）** | 61lag補正後も p=2.9e-17 と最強 | **6月に核を「独立性＋バックテスト」に変更**したため不採用 |
| **中国A株での再現** | pre15 で Δσ=+1.30 (p=0.027, n=3)。**post-pre窓では負** | **イベント3件では結論を出せない**（Webサイトには正直に併記済み） |
| **統合指標α（12指標を束ねる）** | 5年で Δσ=+2.58 → **20年で −0.44（符号反転）** | **長期で再現しない** |
| **地政学イベントでの反応** | e_div Δσ=+0.47, **p=0.378（非有意）** | 効かなかった |
| **flip_rate（符号反転率）** | 当初 p=0.0001 と主張 → 検証で **p=0.692** | **再現しなかったのでサイトから削除済み** |

### 2-2. バックテスト系 → 期間・条件によっては効かない

| 何を | 結果 |
|---|---|

## 5. この研究の射程（先に自分から言う）

> **米国株価指数を中心とした市場では、構造の崩れ（e_div）を使うと下落を有意に回避できる**
> （20年の前進検証で最大下落 −16%、ランダム500本中の上位1%、VIXにも勝つ）。
>
> ただし:
> - ①**個別の暴落を予知しているわけではない**（先行/後追いが混在、総合はmixed）
> - ②**株価指数を抜くとシグナルが消える**
> - ③**非米国市場では効かない**
> - ④**持ち続けには勝てない**（リターン・Sharpeで劣る）
>
> だからこれは**普遍的な法則でも予知でもなく、米国市場における「構造の異変の検知力」の実証**。

**先に限定する方が、後から限定させられるより強い。**

## 6. 正直に認識しておくべき構造的な弱点

**否定的な結果の出方に、気になるパターンがある**:

- **期間を伸ばす（20年）** → バックテストは有意になる（p=0.01）が、**イベントスタディの反応は減衰・符号反転**する
- **期間を縮める（5年）** → イベントスタディの反応は強いが、**バックテストはランダムに負ける**（p=0.704）

つまり「効いた」と言える期間が、**指標の種類ごとに食い違っている**。加えて `gamma_divergence_index.json` は「効果の大半は**2025年4月の大型関税5件**由来」と示し、`robustness_cluster_perm.json` は「n=5個別では非有意、クラスタでのみ有意」と示している。

**イベントスタディ側の発見が、実質的に2025年4月の単一イベント群に支えられている可能性は否定できない**。——これも**イベントスタディをポスターに載せていない理由の1つ**。ポスターの主張（独立性＋20年の前進検証）はこの問題の外にある。

**比較の定義が2つあることに注意**: 「休む率を e_div に揃える」比較（上の実現ボラ OOS・重なり 61〜85%）では e_div ≈ 実現ボラ。「各自の80パーセンタイル」比較（すぐ上の行）では実現ボラは休む日が少なく Sharpe が上、最大下落は e_div が上。どちらも正しく、問いが違う。

**休む率を動かして揃えた比較（2026-09-30、検証ページ [q2.html](https://hajimedayo328.github.io/market-graph-presentation/q2.html)）**: しきい値を train の 50〜95 パーセンタイルで掃引し、実際の休む率が e_div（しきい値80）に最も近い点どうしで比べると、実現ボラ20日は 20年: 休む率 46% で最大下落 **−14.0%**（e_div 44% で −16.2%）、Sharpe 0.56（e_div 0.62）。15年: −14.9% vs −16.2%、0.47 vs 0.49。10年: −11.4% vs −17.0%、0.62 vs 0.40。**同じ日数だけ休むなら、最大下落は実現ボラの方が浅い。Sharpe は20年・15年で e_div が少し上、10年は逆。** fold ごとに e_div の休む率へ合わせる揃え方（上の表）では 20年 −17.4% で、揃え方によって −14.0〜−17.4% と動く。でたらめ（e_div と同じ回数・長さ、500本）比: e_div の最大下落は 20年で 99%、15年で 98%、10年で 94% のでたらめより浅い。Sharpe はでたらめの 34% が e_div 以上（20年）で区別がつかない。生成は `scripts/build_q2_page.py`、データは `data/q2_page_data.json`。

**結論**: e_div は「相関構造から作った、**今の荒れ具合の別の測り方**」。方向の情報はなく、先取りもしていない。単純ボラルールに対する上乗せは薄い（長期で僅差の勝ち、直近で負け）。VIXルールには勝つが、実現ボラの方が手強い相手だった。

**揺らいでいないもの**: 2つの位相不変量（形＝大きさ／符号）が独立であること。先読み排除・ランダム比較・単純ルール比較まで自分で回した検証パイプライン。

**Ferreira et al. 2021（arXiv:2104.06254、ポスター引用済み）との対応（2026-09-19 確認）**: 彼らは各国株式の符号付きネットワークで 2011年8月以降に均衡→不均衡の転移を報告。うちの40資産（株・為替・金・国債・VIX 混在）の20年系列では **2011年8月に段差はない**（前後1年の n_unb 平均差 −2.0、全期間の同幅差の分位 0.32＝普通）。代わりに **2013〜2015年にかけて緩やかに不均衡化**（年平均 n_unb 2008–12: 9〜14 → 2015以降: 25〜34、均衡率 0.95〜0.97 → 0.85〜0.88、辺数は 314〜363 → 230〜280 に減少）。2008–09年は n_unb 最小・均衡率最大・辺数最大＝「全面崩壊＝一斉に同調＝均衡」で、Bartesaghi et al. 2025（arXiv:2512.10606）の前提「危機では資産が同じように動く」と同じ向き。文章化では「転移の時期は資産集合で違う（単一国株 2011 vs 資産横断 2013–15）」と書く。両論文とも要旨のみ確認、本文は未読。

**ただし「独立」は L¹ と n_unb の組に特有ではない**（2026-09-18 確認、`multi_indicators_w30.csv` 2021–2026）: 形の指標どうし（L¹/L²/L∞/穴の数/平均寿命/エントロピー）の平均 |r| = 0.49、符号の指標どうし（n_unb 系4種/均衡率）= 0.43、**形×符号の間 = 0.14**。つまり「符号の情報は形の情報に含まれていない」という2系統の性質であって、どの形指標とどの符号指標を組んでもほぼ同じことが言える。この事実で何ができるかはまだ示せていない（差分 e_div は単純ボラルールと同格）。

**次の書き物（卒論・論文）での主張の組み替え案**: 「下落の先取り」→「**相関ネットワークの位相からボラティリティ・レジームを再構成できる／2つの位相不変量は独立**」。今回の否定的結果は隠さず「自分で潰した」と書く。
